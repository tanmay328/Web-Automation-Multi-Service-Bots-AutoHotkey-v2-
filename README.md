# Web-Automation-Bots AHK (AutoHotkey-v2-)

BOT 1 (backlink_all.ahk):
An orchestration engine designed to automate data submission across 20+ classified advertising platforms sequentially. It features an advanced control GUI to manage live execution statistics, custom runtime caps, and graceful thread termination loops.

BOT 2 (EmailBot.ahk)
An automated portal client that handles multipart data and asset uploads. It uses direct browser DOM manipulation and dynamic XPath relative traversal to bypass standard user interfaces and programmatically submit form payloads.

BOT 3 (whatsapp service.ahk)
A high-precision background scraper built to process automated text and database row states. The script injects custom analytical JavaScript to mathematically evaluate data fields and fires explicit change event bubbles to ensure seamless database synchronization.

Core Libraries Used:
1. FindText.ahk: A high-speed, computer-vision library utilized for grayscale pixel-pattern matching. It serves as an intelligent UI fallback mechanism to visually detect on-screen milestones, page loads, and captcha/error states when traditional browser DOM elements are inaccessible.
2. Built-in AutoHotkey v2 GUI: The native, object-oriented user interface framework utilized to build stateful desktop dashboards that dynamically display live logs, track loop iterations, and capture user input metrics.

Software Concepts Implemented:
1. Hybrid Automation Architecture: Orchestrates high-level system windows and file structures natively via AutoHotkey while simultaneously executing granular webpage interactions by injecting raw vanilla JavaScript payloads straight into the browser DevTools console.
2. Programmatic DOM & XPath Navigation: Bypasses fragile coordinate-based mouse clicking by utilizing advanced XML Path Language (XPath) relative node traversal and standard CSS selectors to isolate and interact with non-ID table elements and dynamic web structures.
3. Asynchronous AJAX & Event Dispatching: Ensures client-side form changes are recognized by modern backend databases by manually constructing and firing native browser events (e.g., new Event('change', { bubbles: true })) to trigger required page scripts.
4. Algorithmic Data Parsing: Employs client-side script arrays to actively scrape raw text strings from web tables, convert data types dynamically, and mathematically calculate structural boundaries (such as computing the maximum available record index in a list).
5. Multi-Step Payload Serialization & Asset Injection: Manages multipart data workflows by handling local operating system clipboards, intercepting and interacting with system file upload dialogs, and dynamically concatenating variables into specific submission payloads.
6. Self-Healing Session & OS Window Management: Implements active cleanup logic using OS window monitors (WinWait, WinActivate, WinExist) to gracefully close background developer instances (WinClose) and prevent system memory leak constraints during infinite loops.
7. Self-Installing Runtime Shortcuts: Features programmatic deployment logic that checks the execution path of the application on launch and silently generates native Windows shortcuts (.lnk) to the desktop for automated user access.
